# F9 远程语音 Android 客户端

原生 Android 输入框接收豆包输入法的识别文字，直接调用现有 AirType PC 服务。无需浏览器，不替换豆包输入法，不更改 PC 的文字粘贴、热词或剪贴板逻辑。

已读取手机 Download 下的 Tasker 备份。F9 按下配置 13 调用任务 19：设置 `%Starting=1`、播放 `camera_focus` 提示音、点击 `(360,1797)`，等待 1 秒后设置 `%Starting=0`；松开配置 18 调用任务 20，仅在 `%Starting=0` 时点击 `(620,2484)`。因此短按保持收音来自这段 1 秒保护时间。固定坐标和点击前的提示音不能确认豆包实际开始收音，新客户端改为查找输入法控件并在确认后反馈。

原始备份保留在 `.local-build/device/xiaomi14/tasker-backup.xml`，没有改写。

## 操作

- 任意已解锁界面按 F9：打开客户端、聚焦输入框、弹出豆包输入法、开始语音。
- 按住不足 1000 ms 后松开：保持免手持收音；再次按 F9 结束。
- 按住达到 1000 ms 后松开：结束收音。启动尚未完成时，松开事件也会保留。
- 远程输入窗口前台时，实体普通 Enter 或小键盘 Enter 向 PC 发送一次回车，不在手机输入框插入换行；长按重复与松开不重复发送。文字正在传输时，回车排在文字后发送。
- 沿用原网页版小键盘映射：F1 向 PC 发送软回车（Shift+Enter），F2 向 PC 发送删除（Backspace）。三种按键均只控制 PC，不改动手机草稿；窗口前台时生效。
- 只有确认语音界面后才发出成功提示；启动失败、结束未确认或发送未确认会明确反馈。
- 连接失败时保留文字，不自动重试 `/type`，避免网络超时造成重复粘贴。
- 最终预览确认且文字请求发出后，手机立即播放短促“嗖”声，不等待 PC 粘贴完成。此声音表示请求已发出；成功状态仍等待 PC 回执，失败仍提示并保留草稿。预览失败、未能发出请求、单独发送快捷键时不播放。音效使用用户提供的 SentMessage 文件，去掉开头约 100 ms 的近乎无声部分，保存为 `res/raw/message_sent.wav`。
- 锁屏需要先解锁；无障碍服务不能绕过系统密码。
- 远程输入页默认全屏，隐藏状态栏和导航栏；从屏幕边缘滑动可临时显示系统栏。输入区随键盘伸缩，底部保留发送、清空、回车、软回车、删除和撤销，设置入口位于右上角。

使用前应关闭 Tasker 的 F9 Key Down / Key Up 两条配置，避免同时点击。本次验收时已观察到这两条配置处于关闭状态；安装脚本不改 Tasker 配置，并保留原有 AutoInput 服务。本应用全局消费 F9；Enter、F1、F2 仅在远程输入窗口前台时消费，其它键继续交给原系统处理。

## 构建

```powershell
.\android-client\build.ps1
.\android-client\install.ps1 -Serial <ADB设备标识>
```

依赖本机 Android SDK 35 和 JDK 17。构建过程运行纯 Java 按键时序检查，再编译、生成 APK、签名并验证签名。

主应用更新和 `tests/run-device-tests.ps1` 的测试包安装共用 `adb-install.ps1`。小米 USB 安装提示出现时，脚本在本次安装期间核对系统安装页面、应用名称和“继续安装”按钮，再按控件位置自动确认；不勾选“拒绝后下次安装不再提示”。安装必须返回 `Success`，且手机 APK 的 SHA-256 必须与本地文件一致，才报告完成。未知弹窗、已有安装提示、控件不可用或超时会报错。

这是按需构建、签名并通过 `adb install --no-incremental -r` 覆盖安装的开发流程，不是后台持续更新或热重载。只有修改 Android 客户端才需要更新 APK；修改 PC 服务代码不需要重装手机应用。自动确认需要手机已解锁、ADB 已授权且允许模拟点击；直接绕过项目脚本执行 `adb install` 不会启用自动确认。

源码在 `android-client/`；APK、签名密钥、备份及诊断文件在被 Git 忽略的 `.local-build/`。本地调试包标识为 `local.qaa.airtype`。

客户端默认连接 `http://192.168.31.8:15000/`，可在设置页修改。当前实现适用于现有局域网 HTTP 服务；没有实现 Cloudflare 加密通道。

## 接口

- `HEAD /last_text`：检查现有 PC 服务，不读取上一条文字。
- `POST /input_preview`：同步输入预览和热词剪贴板采集。
- `POST /type`：语音最终提交后发送文字；按钮可发送 Enter、Backspace 和 Undo。

预览和最终发送共用一个串行队列，最终发送先确认最后一次预览完成。

小米的后台打开界面权限 `MIUIOP(10021)` 最初为 `ignore`，导致后台启动被系统日志明确拒绝。允许后可从桌面打开客户端。USB 更新 APK 会异步重置此项，所以安装脚本在更新后重新配置该应用的权限，并要求连续三次读回 `allow` 才报告成功。
